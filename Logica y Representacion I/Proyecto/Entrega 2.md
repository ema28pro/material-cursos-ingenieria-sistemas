# Proyecto de aula . Entrega final

**Resultados de aprendizaje** :
Implementar las funcionalidades del proyecto seleccionado a partir del diagrama de clases diseñado.

**Modalidad** : En equipos de 3 personas mínimo 2.

**Valor **: 20%.

**Fecha entrega** : Lunes 14 al medio dia

**Sustentaciones** : 14, 15 y 17 de julio

**Indicaciones** :

- Ajusta el diagrama de clases de acuerdo a la realimentación de la primera entrega.
- Genera un proyecto en el cuál crees las clases respectivas con sus respectivos atributos, constructores, getter/setter y métodos relacionados. En este, se deben aplicar los fundamentos de la filosofía orientada a objetos.
- Diseña el menú principal de la aplicación, que permita acceder a las funcionalidades del proyecto.
- Participa en la socialización y sustentación del proyecto. En la socialización el profesor elijará quien o quienes presentan el trabajo. En este sentido, todos los integrantes deberán conocer por completo el proyecto.

**Nota** : La no asistencia a la sustentación es una nota de cero.

**Criterios de valoración de la evidencia** :

A continuación, se especifican los criterios de evaluación de esta primera entrega.

| Criterio | Cumple (20 puntos) | Cumple parcialmente (10 puntos) | No cumple (0 puntos) |
| - | - | - | - |
| Identifica correctamente las clases que intervienen en la solución y especifica sus relaciones en el diagrama de clases | | | |
| Entrega el código fuente (archivos ipynb o py) de cada una de las clases definidas en el diagrama de clases | | | |
| Explica lo que pasa en cada método o función | | | |
| Crea un menú funcional y qué permita acceder a las funcionalidades el proyecto | | | |
| Asiste y participa a la socialización del proyecto | | | |
