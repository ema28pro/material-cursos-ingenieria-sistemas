Comprender cómo leer y construir pruebas por inducción matemática es un objetivo clave del aprendizaje de las matemáticas discretas. Muchos enunciados matemáticos afirman que una propiedad es verdadera para todos los números enteros positivos. Un propósito de esta unidad, y del curso, es brindar al estudiante una comprensión completa de la inducción matemática que se utiliza para probar resultados de este tipo.

Las pruebas que usan inducción matemática tienen dos partes: primero, muestran que el enunciado se cumple para el entero positivo 1; segundo, muestran que, si el enunciado se cumple para un entero positivo, entonces también se debe cumplir para el siguiente entero mayor. Esta se puede utilizar para demostrar una enorme variedad de resultados.

En matemáticas discretas se describen conjuntos enumerando sus elementos o dando alguna propiedad que los caracteriza y, además, se dan fórmulas para los valores de las funciones. Hay otra forma importante de definir tales objetos, basada en la inducción matemática: se especifican algunos términos iniciales y se da una regla para encontrar valores posteriores a partir los ya conocidos.

Los conjuntos se pueden definir enumerando algunos de sus atributos y dando reglas para construir elementos de los que ya se sabe que están dentro de ellos (de los conjuntos). Estas se conocen como definiciones recursivas y se utilizan en matemáticas discretas y ciencias de la computación.

Una vez que se han definido el conjunto recursivamente, se puede usar un método llamado inducción estructural para probar los resultados sobre este conjunto. Cuando se especifica un procedimiento para resolver un problema, este siempre debe resolverlo correctamente.
